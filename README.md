# Shraddha – Practical Online Courses for Students

Shraddha is a premium educational platform built for Class 10th, Intermediate, and B.Tech students across India. We provide high-quality, practical, and project-based courses designed to take students beyond textbook learning.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Design Principles**: Industry-grade "Design Engineering" patterns with custom easings and responsive micro-interactions.

## Features

- **Premium UI/UX**: Clean, modern interface with glassmorphism and smooth transitions.
- **Course Management**: Detailed course pages with curriculum breakdowns and interactive elements.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Performance**: Built with Next.js Turbopack for lightning-fast development and optimized production builds.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
